Gaia’s Secret Agents · Pinterest API Review Demo

Connect Pinterest

Authorization Code OAuth followed by a live Pinterest Sandbox board-and-Pin API action.

1

Authorize Pinterest

The user is sent to Pinterest’s official OAuth screen and approves the minimum permissions required for boards and Pins.

2

Return to GSA

Pinterest returns a short-lived authorization code to this registered callback page. No Pinterest password or session cookie is collected.

3

Exchange code server-side

The one-time code is sent to the private GitHub Actions runner, which uses the encrypted app secret to request an OAuth access token and immediately create a Sandbox board and Pin.

3

Run the server-side OAuth test

Copy the one-time authorization code, open the runner, paste it into auth_code, and choose Run workflow. The code and token are masked in the workflow.
