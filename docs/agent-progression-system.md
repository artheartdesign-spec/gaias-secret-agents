# Gaia’s Secret Agents — Agent Progression System v1

**Purpose:** Turn individual missions, badges, Agent Super Powers and Character Files into one continuing Agent journey.

## Core rule

Ranks are earned through **verified field skills**, not by collecting random rewards.

The product layers stay separate:

- **Mission number** = where the child is in the story.
- **Character File number** = where a character sits in the Secret Headquarters archive.
- **Mission badge** = what the Agent accomplished in that mission.
- **Agent Super Power / field skill** = a capability developed through the mission.
- **Rank** = longer-term progression across multiple missions.
- **Secret Meeting Cards** = optional family/friends play; they never block mission or rank progress.

Recruit means the child has an active Agent File and official credentials.

> **2 / 5 field skills toward Field Agent clearance**

Do not name Skills 3–5 until those missions are designed.

### Investigator

Reserved for a later season milestone.

Do not publish a numeric threshold yet.

### Specialist

Reserved for later progression.

Do not publish a numeric threshold yet.

### Senior Agent

Reserved as a long-term rank.

Do not publish a numeric threshold yet.

This keeps the rank ladder visible without promising a progression system that has not yet been fully built.

## Agent Record layout

Every Agent Record should contain five visible areas.

### 1. Rank

- current rank
- next clearance
- progress toward next clearance

Example:

> RECRUIT  
> FIELD AGENT CLEARANCE: 2 / 5 FIELD SKILLS VERIFIED

### 2. Missions

- Starter Kit — Induction
- Mission 01 — Ocean Discoverer
- Mission 02 — Operation: Pollinator
- future missions shown only after release

### 3. Agent Super Powers / field skills

- Curiosity
- Observation
- future skills remain CLASSIFIED

### 4. Badges + Character Files

Badges and Character Files are recorded but do not independently determine rank.

## Mission completion rule

A full mission is complete when the child:

1. completes the core investigation,
2. records or debriefs what they found,
3. takes the mission’s achievable real-world action,
4. earns the mission badge and Agent Super Power.

The Character File can then be revealed.

Secret Meeting Cards remain available after mission completion.

---

## Fiction language

Use progression inside the Agency voice.

Examples:

> **AGENT RECORD UPDATED**  
> Observation verified.  
> Field Agent clearance: 2 / 5 skills.

> **ARCHIVE FILE UNLOCKED**  
> Character File 004: SPRIG is now available.

> **CLEARANCE PENDING**  
> Three field skills remain classified.

This makes retention part of the story rather than a generic loyalty mechanic.

---

## Commercial purpose

The progression system answers:

> “What happens next?”

A completed mission should create three reasons to continue:

1. the story has an unresolved thread,
2. the Agent is progressing toward a rank,
3. the archive still contains Character Files and skills that have not been unlocked.

Do not turn this into points, coins or a complicated reward economy.

The strength is that the child is building an **Agent history**.
