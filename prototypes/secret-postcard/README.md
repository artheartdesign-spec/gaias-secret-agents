# GSA Secret Postcard prototype

Review-only prototype for a free digital postcard creator.

- No database
- No paid API
- No login
- Client-side PNG export
- Web Share API with download fallback
- Does not modify the live GSA site

Open `prototypes/secret-postcard/index.html` locally or through GitHub Pages when ready.

This prototype is on the `feature/secret-postcard` branch and has not been merged into `main`.
